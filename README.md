# AI CRUD App

A simple AI-powered CRUD application built with Node.js, Express, MongoDB, and Groq AI.  
Users can manually manage data or use natural language commands like "add John 20" to interact with the database.

---

## Features

- Add users manually (frontend form)
- AI-powered commands (add, delete, edit)
- MongoDB database integration
- Simple frontend (HTML, CSS, JavaScript)
- REST API backend with Express
